# Análise do GitHub 

Projeto desenvolvido em C# com o intuito de emitir os commits de um usuário em um determinado reposítorio


---

## Funções 
- Mostrar a quantidade de commits em uma determinada data
- Mostrar os comentarios, o momento exato de quando foi "commitado" e o nome do usuário
- Possível exportar para o Excel ou para um arquivo .txt
- Receber uma análise dos commits pelo ChatGPT 4.0 mini



## Quais chaves APIs eu preciso para o código funcionar ?
Você precisa ter uma chave do GitHub e uma do ChatGPT


## Como eu posso ter uma chave API do Git ?
Para ter uma chave API do GitHub basta entrar neste link: https://github.com/settings/personal-access-tokens clicar em "Generate new token" e seguir o passo a passo do site
OBS : É obrigatório você entrar na sua conta ou cadastrar uma conta para ter uma chave



## E para ter uma chave API do ChatGPT ?
Para ter uma chave API do ChatGPT você deve seguir este link: https://platform.openai.com/settings/organization/api-keys clicar em "Create new secret key"
OBS: Copie a sua chave imediatamente, pois não será possível ter acesso novamente.
OBS 2 : É obrigatório você entrar na sua conta ou cadastrar uma conta para ter uma chave
